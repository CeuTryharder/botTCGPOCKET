⚙️ Cómo funciona

El bot opera en cuatro módulos que se comunican entre sí:

Emulador Android (BlueStacks / Nox / AVD)
↕ ADB (Android Debug Bridge)
ADBController ↔ Vision (OpenCV)
↕
BotTasks (lógica de rutinas)
↕
main.py (menú interactivo)

🎮 ADBController

Se comunica con el emulador: toma capturas, realiza taps y swipes.

👁️ Vision

Usa OpenCV para buscar imágenes de referencia en la pantalla del emulador.

🤖 BotTasks

Contiene la lógica de cada rutina: farmeo de batallas y reclamar misiones.

🖥️ main.py

Punto de entrada con menú interactivo en consola para seleccionar tareas.

⚙️ Instalación

1. Clonar el repositorio

git clone https://github.com/TU_USUARIO/botTCGPOCKET.git
cd botTCGPOCKET

2. Crear el entorno virtual

# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate

🖼️ Configuración de Plantillas (Obligatorio)

El bot usa reconocimiento de imágenes: necesita pequeños recortes de los botones del juego guardados en bot/templates/. Estos varían según el idioma y resolución de tu emulador, por lo que debes crearlos tú mismo.

💡

ConsejoRecorta solo el botón, sin demasiado fondo alrededor. Un recorte limpio mejora mucho la precisión del bot.

Plantillas necesarias

ArchivoTareaQué capturar
battle_btn.pngFarmeoBotón para iniciar una batalla en solitario
auto_battle_btn.pngFarmeoBotón de auto-batalla dentro de la partida
ok_btn.pngAmbasBotón "OK" de confirmación / fin de batalla
next_btn.pngFarmeoBotón "Siguiente" o "Continuar"
missions_tab.pngMisionesPestaña/icono de Misiones en el menú principal
claim_all_btn.pngMisionesBotón "Reclamar Todo"

Cómo crear las plantillas

  1. Navega a la pantalla correctaAbre el emulador con el juego en la pantalla donde aparece el botón que quieres capturar.
  2. Captura la pantallaCon el entorno virtual activado, ejecuta:
    python bot/screenshot.py
    Se genera un archivo screenshot_XXXXXX.png en la raíz del proyecto.
  3. Recorta el botónAbre la imagen con un editor (Preview en Mac, Paint en Windows) y recorta únicamente el botón.
  4. Guarda en templatesGuarda el recorte en bot/templates/ con el nombre exacto de la tabla de arriba.
  5. RepiteRealiza este proceso para cada una de las plantillas necesarias.

🚀 Uso del bot

1. Conectar ADB al emulador

🔧 Solución de problemas

ProblemaSolución
El bot no encuentra los botonesRecrea la plantilla con recorte más preciso. Verifica que el nombre del archivo sea exacto.
adb: command not foundInstala Android SDK Platform Tools y añade la carpeta al PATH.
Error de conexión ADBEjecuta adb kill-server && adb start-server y reconecta con el puerto correcto.
ModuleNotFoundErrorActiva el entorno virtual y ejecuta pip install -r requirements.txt.
La resolución del emulador cambióVuelve a crear todas las plantillas con la nueva resolución.
